\# Result



\## Project Completion



The Azure Virtual Machine Scale Set autoscaling project was successfully implemented.



The project includes:



\* Azure Resource Group

\* Azure Virtual Machine Scale Set

\* Ubuntu Linux VM instances

\* Azure Virtual Network

\* Network Security Group

\* Azure Monitor

\* CPU-based Autoscale rules

\* SSH connectivity

\* CPU load testing



\## Autoscaling Configuration



The VMSS was configured with:



\* Minimum instances: 2

\* Maximum instances: 5

\* Default instances: 2

\* Scale out when average CPU is greater than 70%

\* Scale in when average CPU is less than 30%

\* Scale out action: Increase instance count by 1

\* Scale in action: Decrease instance count by 1



\## Outcome



The project demonstrates how Azure VM Scale Sets can automatically adjust the number of VM instances based on CPU utilization.



Azure Monitor provides the CPU metrics, while Azure Autoscale uses the configured thresholds to control the VMSS instance count.



\## Conclusion



The Azure VMSS Autoscale project was successfully completed and documented with architecture, deployment, autoscaling, monitoring, testing information, and screenshots.

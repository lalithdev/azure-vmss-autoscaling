\# Azure Services Used



| Azure Service | Purpose |

|---|---|

| Azure Resource Group | Organize all project resources |

| Azure Virtual Machine Scale Sets | Create and manage multiple VM instances |

| Azure Virtual Network | Provide network connectivity |

| Network Security Group | Control inbound and outbound traffic |

| Azure Monitor | Monitor VMSS metrics such as CPU usage |

| Azure Autoscale | Automatically increase or decrease VM instances |

| Azure Virtual Machines | Run Ubuntu VM instances |

| Azure SSH | Securely connect to the Linux VM |

| Azure Metrics | Monitor Percentage CPU |
